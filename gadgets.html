04发明公式：从"想做点什么"到"具体做什么"

大部分好点子都能用这五个套路套出来。卡壳的时候就翻回去看。

① 感知 → 决策 → 执行

任何自动化装置都只有这三段。先写清楚这三句话，再想硬件怎么填：
"我感知什么状态 → 按什么规则判断 → 用什么执行器动作"。

② 替换法

找一个你每天重复的手动动作——关灯、拉窗帘、按键盘、浇水——把"手"换成舵机 / 电机 / 水泵 / 继电器。这是最容易出成果的路。

③ 加感法

给已有物件装一只"眼睛"：门、灯、花盆、垃圾桶、书架、衣架。它会知道自己现在的状态，于是就有了自动化的前提。

④ 闭环法

开环做完就加反馈：限位开关、编码器、摄像头、电流检测。加了反馈，机器才"知道自己做成了没有"——这正好是自动控制原理那门课的核心。

⑤ 拆解对标

捡一个便宜小家电（旧计算器、旧打印机、坏鼠标）拆开，看别人的机构和控制怎么解决同一个问题。对机械专业来说，这是最划算的学习方式。

05时间、课程、竞赛怎么排

每周只投 2～3 小时

  1. 固定时段：比如周日下午，雷打不动。碎片时间只用来查资料。
  2. 一个里程碑一个周末：做不完就砍功能，别让项目烂尾——烂尾最伤热情。
  3. 每学期 1 个能录视频的作品 + 1 个能写进简历的系统，够了。
  4. 先跑通再优化：能演示的丑东西 > 永远在调试的完美方案。

和课程、竞赛挂钩

  1. 课程对应：单片机 → P1；传感器 → 感知类项目；自动控制原理 → PID 调速/温控；电机拖动 → 步进/直流电机项目；PLC → 传送带分拣。
  2. 课设直接复用：机械原理/机械设计课设的结构件，可以拿来做项目的外壳和机构。
  3. 竞赛：电子设计竞赛、机械创新设计大赛、工程训练综合能力竞赛、中国智能制造挑战赛、挑战杯。大二开始攒，别等大三。
  4. 实验室：找老师/学长进实验室，工具、器件、指导全有了——这是性价比最高的一步。

作品集怎么留证据

每个项目留四样东西：演示视频（30 秒，能跑就行）、接线/结构照片、BOM 清单、踩坑记录（面试时最值钱的部分）。 放 GitHub 或一个网盘文件夹，半年后你会谢谢自己。
